# 算法与能力边界

牌伴提供可解释的启发式建议，不声称最优策略、真实胡牌概率或精确净积分期望。

## 复用范围

普通手牌向听复用 `@kobalab/majiang-core@1.4.1`（MIT），适配集中在 `src/hand.js`。测试以独立递归拆牌程序对照普通胡判定。

本项目适配七对四张算两对、十三烂、清一色奖励、逐付款人的庄家倍率、点炮旁观付款和独立杠分。没有沿用日麻算番、振听、必须有役等规则。

## 建议如何产生

`src/advisor.js` 只使用用户记录的公开信息及自己的手牌。Worker先给出快速排序，再补充有限结构搜索。候选包括弃牌、吃碰后的最佳弃牌、杠和不响应；合法胡牌默认建议收下。

排序综合结构距离、有效未见牌、连接形态、特殊牌型倾向、听牌后的结算收入、杠的即时积分，以及对手副露和轮次等公开信号。权重是工程基线，没有真实牌谱校准。

“未见”表示 `4 − 已知可见张数`，包含对手暗手中的牌，不能当成牌墙剩余数或摸入概率。未知暗杠牌面不作猜测。

## 已有检查及局限

- 判胡、特殊结构、积分守恒、轮转、撤销、存档重放、绝张死听等由 `npm test` 检查。
- `scripts/evaluate-strategy.mjs` 提供固定随机种子、轮换座位的策略实验。实验中的对手策略和未定规则假设只是仿真约定。
- 当前没有完整隐藏手牌概率模型、跨局连庄价值、完整净积分搜索或真实玩家验证。
- 当输入有误、信息不完整或现场使用了未支持规则时，建议和自动结算都可能不适用。

反馈建议请附可复现的匿名牌例和具体操作步骤，不必提供真实参与者身份。
